# 书稿自检脚本

## 用途
自动检查教材 `.docx` 稿件的**机械类问题**，避免人工逐页翻检。

## 用法

```bash
# 检查单册
python3 tools/check_docx.py "项目5 数据清洗质量控制与第一个智能体.docx"

# 批量检查，并输出 Markdown 报告
python3 tools/check_docx.py *.docx --md 自检报告.md
```

仅依赖 Python 3 标准库（`zipfile` / `re` / `html`），无需安装任何第三方包。

## 检查项

| 编号 | 检查项 | 级别 | 说明 |
|:--:|---|:--:|---|
| C1 | 题注居中 | 必改 | 图题、表题是否设置居中 |
| C2 | 题注空格 | 必改 | `图1-1` / `表1-1` 与题名之间是否有空格 |
| C3 | 题注未被引用 | 提示 | 有题注但正文从未提到 |
| C4 | 编号断号 | 必改 | 图/表编号是否连续 |
| C5 | 悬空交叉引用 | 必改 | 正文引用了不存在的图号/表号 |
| C6 | 引号配对 | 必改 | 左引号 `“` 与右引号 `”` 数量是否相等 |
| C7 | 引号次序 | 必改 | 是否把右引号 `”` 当左引号使用 |
| C8 | 英文直引号 | 必改 | 正文残留 `"` |
| C10 | 残留批注 | 提示 | 文档中是否还挂着未处理批注 |
| C11 | AI 行文特征 | 提示 | 疑似 AI 写作的高频特征词与密集排比 |

## 已验证
- 对「项目1 修改稿（修订前）」：准确查出 6 类必改问题。
- 对「项目1 修订稿（修订后）」：必改项归零。

## 注意
- C11 只是**提示**，AI 行文特征需人工判断，脚本无法替代润色。
- 引号批量修复依赖"每段引号数量为偶数"这一前提；若某段引号为奇数，脚本会报出"引号不配对"，需人工处理该段。
